# 근짱 일본어 · JLPT N3 — GitHub Pages demo

정적 GitHub Pages 기반 PWA입니다. 14일 테마형 학습 코스에서 매일 한자, 어휘, 문장 표현, 퀴즈를 연습할 수 있습니다. 자료는 JLPT 공식 어휘 목록을 그대로 복제한 것이 아니라 N3 수준을 목표로 구성한 학습 세트입니다.

## 학습 구성

- 14개 테마 수업, 날짜별 한자·어휘·표현·퀴즈
- 날짜별 진도 저장 및 코스 선택
- 기기 브라우저에 학습 진행과 메모 저장
- PWA 설치 지원

## J-pop 메뉴

GitHub Pages는 정적 파일 호스팅이라 서버 측 YouTube Data API 검색을 실행하지 않습니다. 검색 버튼은 YouTube 검색 결과를 새 탭으로 열고, 선택한 영상 링크를 앱에 붙여넣으면 앱 안의 공식 YouTube 플레이어에서 들을 수 있습니다. API 키는 저장소에 넣지 않습니다.

## 설치

- Android/Chrome: 공개 사이트에서 브라우저의 앱 설치 또는 홈 화면에 추가를 선택합니다.
- iPhone/iPad: Safari의 공유 메뉴에서 홈 화면에 추가를 선택합니다.
- HTTPS가 제공되며, 학습 자료와 메모는 같은 기기의 브라우저에 저장됩니다.
